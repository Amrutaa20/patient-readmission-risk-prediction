Project Overview

Project: MediPredict AI — Patient Readmission Risk Prediction
Domain: Healthcare
ML Task: Binary Classification (Readmitted within 30 days)
Problem Statement:

Predict whether a discharged patient is likely to be readmitted within 30 days using demographic information, diagnosis categories, treatment history, and hospital utilization records.

Objectives:
  • Estimate 30-day patient readmission risk early
  • Improve healthcare delivery quality and care coordination
  • Reduce avoidable hospital readmission costs
  • Support clinical staff in discharge planning

Dataset Information

Dataset: Diabetes 130-US Hospitals (1999-2008)
Source: UCI Machine Learning Repository
Records Used: 101,766 encounters (after preprocessing)
Target Variable: Readmitted in <30 days (1: Yes, 0: No)
Features Used: Age, Gender, Diagnosis (ICD-9), Medication Count, Previous Admissions, Length of Stay

Model Information

Algorithm: Random Forest / XGBoost Classifier
Training Method: Stratified Train/Test Split (80/20)
Evaluation Metrics: ROC-AUC, F1 Score, Recall, Precision, PR-AUC
Operating Threshold: 0.40 (Tuned to prioritize Recall for clinical safety)
Model Version: v1.0.0 (Production candidate)
